# Best Paints — покраска коммерческих помещений

Статическая вёрстка под дальнейший перенос на Tilda или LP.
Чистый HTML + CSS + JS, без сборки и зависимостей.

```
index.html            вся разметка, блоки размечены комментариями
assets/styles.css     стили, разбиты по номерам секций
assets/app.js         поведение (меню, модалка, FAQ, бриф)
assets/logo-bestpaints.png
```

## Где лежит

**Публичный адрес:** https://podaritepanamery.github.io/best-paints-commercial/
Репозиторий: https://github.com/podaritepanamery/best-paints-commercial

Деплой при любой правке:

```bash
git add -A && git commit -m "правка" && git push
```

GitHub Pages пересобирает сайт сам, обычно за минуту.

Превью закрыто от индексации через `robots.txt`: боевой сайт будет на домене
клиента, дубль в поиске ему только навредит. Когда понадобится открыть,
удалите `Disallow: /` из `robots.txt`.

Открыть локально:

```bash
python3 -m http.server 4173
```

## Как добавить фотографии работ

Блок «Наши работы», секция `#works`. Повторяет портфолио-панель LP:
слева состав работ и цифры, справа сетка снимков с метками БЫЛО / СТАЛО.

1. Положите снимки в `assets/works/` - **1600 × 1200**, jpg или webp.
2. Внутри нужного `.shot` замените заглушку на картинку:

```html
<!-- было -->
<div class="slot">
  <i class="ph ph-image" aria-hidden="true"></i>
  <b>Фото</b><span>1600 × 1200</span>
</div>

<!-- стало -->
<img src="assets/works/01-before.jpg" alt="Торговый зал до начала работ"
     width="1600" height="1200" loading="lazy" decoding="async">
```

Метки `.shot__label` (БЫЛО / СТАЛО) оставьте на месте.

3. Заполните три строки `.case__stat`: срок, площадь, тип объекта.
   Снимите у них класс `is-ph`, когда подставите реальные значения.

Кейсов сейчас три, добавляются копированием блока `<article class="case">`.

## Как добавить видео

Блок `05 / Видео`, секция `#video`. Четыре слота 16:9.
Замените `<div class="slot"> … </div>` внутри `.vid__media` на один из вариантов:

```html
<!-- свой файл -->
<video src="assets/video/01.mp4" poster="assets/video/01.jpg"
       controls preload="none" playsinline></video>

<!-- YouTube / VK / Rutube -->
<iframe src="ССЫЛКА_EMBED" title="Подготовка помещения"
        loading="lazy" allowfullscreen></iframe>
```

Заголовки под видео уже проставлены по смыслу, меняются в `.vid__body`.

## Технические решения

**Шрифт.** TildaSans, тот же вариативный файл, что на lp.best-paints-bp.ru
(`assets/fonts/TildaSans-VF.woff2`, 85 КБ, веса 250-1000). Собственного курсива
в нём нет, поэтому наклон зелёных акцентов синтезирует браузер - ровно так же,
как это работает на самом LP. Правило `.accent` в `styles.css`.

**Снятая с LP система.** H1 67/70 вес 600 с зелёным курсивным `<em>`;
H2 45/47 вес 400 с `<strong>` 700; текст 18/24; зелёное тире 30 × 3 px слева
от каждого заголовка (класс `.dashed`); фоны секций чередуются `#ffffff`
и `#e6e1d6`; кнопка зелёная, 17px/600.

**Иконки.** Phosphor Icons с CDN, класс `ph ph-<имя>`.
Ничего не нарисовано вручную.

**Единая система форм.** Кнопки 6px, карточки 16px, картинки внутри карточек
10px, поля ввода 7px. Таблетки в шапке - полное скругление, как в макете «НОВА».
Правило записано в шапке `styles.css`.

**Анимации.** Появление блоков на `IntersectionObserver`, без обработчиков
`scroll`, анимируются только `transform` и `opacity`. Полностью отключаются
при `prefers-reduced-motion: reduce`.

**Бриф.** Форма `#estimate` собирает текст прямо в браузере, никуда его не
отправляет. Готовый бриф можно скопировать, скачать `.txt` или открыть
в WhatsApp с уже подставленным текстом.

**Тема.** Сайт светлый, одна тема на всю страницу (`color-scheme: light`) —
так же, как на обоих исходных сайтах и так же, как будет на Tilda.

## Перенос на Tilda / LP

Секции независимы: каждая `<section>` вместе со своим блоком стилей
(они пронумерованы в `styles.css` теми же номерами) переносится в отдельный
блок T123 без переделки. Общие токены из `:root` имеет смысл положить один раз
в настройки сайта, а `app.js` — в подключаемые скрипты.
